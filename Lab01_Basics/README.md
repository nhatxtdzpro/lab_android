# Lab01 · Bốn bài cơ bản

Tạm giả định bốn bài giao diện là Happy Birthday, Compose Article, Task Manager và Compose Quadrant. Có menu chuyển bài và nút quay về.

## Mở và chạy

Android Studio → Open thư mục `Lab01_Basics` → JDK 17 hoặc 21 → Android SDK 35 → Run trên Android API 24+.

Hoặc chạy `gradlew.bat :app:assembleDebug` trong thư mục này. APK ở `app/build/outputs/apk/debug/app-debug.apk`.

Trên máy hiện tại `local.properties` trỏ SDK `D:/DATAAPP/Android`; máy khác để Android Studio tạo lại đường dẫn.

## Kiểm tra thủ công

Mở từng màn hình, nhấn nút quay về hoặc Back. Xoay máy để kiểm tra giữ bài đang chọn.

## Lưu ý

Đề bốn bài cụ thể chưa được cung cấp; cần đối chiếu lại khi có đề.

## Nguồn

Tự triển khai bằng Kotlin/Jetpack Compose.
