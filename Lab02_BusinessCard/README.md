# Lab02 · Business Card

Danh thiếp Android với tên, nghề nghiệp, số điện thoại, mạng xã hội và email.

## Mở và chạy

Android Studio → Open thư mục `Lab02_BusinessCard` → JDK 17 hoặc 21 → Android SDK 35 → Run trên Android API 24+.

Hoặc chạy `gradlew.bat :app:assembleDebug` trong thư mục này. APK ở `app/build/outputs/apk/debug/app-debug.apk`.

Trên máy hiện tại `local.properties` trỏ SDK `D:/DATAAPP/Android`; máy khác để Android Studio tạo lại đường dẫn.

## Kiểm tra thủ công

Chạy ứng dụng, kiểm tra giao diện trên màn hình dọc/ngang. Thay thông tin liên hệ trong MainActivity.kt trước khi nộp.

## Lưu ý

Điện thoại, email và tài khoản xã hội hiện là dữ liệu mẫu.
